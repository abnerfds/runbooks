# 📚 Dev Playbook & TIL (Today I Learned)

Bem-vindo ao meu repositório pessoal de documentação, runbooks e resoluções de problemas. 

Como desenvolvedor Full Stack, lido diariamente com desafios que vão desde a construção de interfaces até a configuração de servidores e automação de infraestrutura. Criei este espaço para documentar incidentes reais, causas raiz e o passo a passo das soluções que apliquei.

O objetivo aqui é criar uma base de conhecimento confiável (para mim e para a comunidade) para que nenhum tempo seja perdido resolvendo o mesmo problema duas vezes.

## 🗂️ Categorias de Conhecimento

Aqui estão as principais áreas documentadas neste repositório:

### ☁️ Cloud & DevOps (Infraestrutura)
* **OCI (Oracle Cloud) / AWS / GCP:** Resolução de acessos, instâncias bloqueadas, gerenciamento de discos e permissões.
* **Docker & Containers:** Problemas de build, redes isoladas e orquestração de ambientes de desenvolvimento.
* **Linux (Ubuntu):** Administração de sistemas, GRUB, Initramfs, e gestão de usuários/grupos.

### ⚙️ Backend & APIs
* **PHP & Swoole:** Otimização de performance, arquitetura e integrações REST.
* **C# / .NET:** Configurações de ambiente, debugs e arquitetura de software.

### 🎨 Frontend
* **React:** Gerenciamento de estado, consumo de APIs e resoluções de bugs de interface.

### 🗄️ Bancos de Dados
* **SQL:** Otimização de queries, gerenciamento de conexões (via DataGrip/outros) e migrações.

## 📝 Estrutura das Documentações

Todos os registros de problemas seguem um padrão de Post-Mortem/Runbook para facilitar a leitura rápida. Cada arquivo `.md` geralmente contém:

1. **O Problema / Sintomas:** O que quebrou ou qual foi a mensagem de erro.
2. **Causa Raiz:** O motivo técnico pelo qual a falha ocorreu.
3. **Solução Aplicada:** O passo a passo exato (comandos e scripts) usado para resolver.
4. **Prevenção:** O que foi configurado ou aprendido para evitar que o problema se repita.

## 🚀 Como Navegar
Sinta-se à vontade para explorar as pastas do repositório. Se você chegou aqui porque esbarrou em algum erro parecido no Google ou no GitHub, espero que as anotações te ajudem a economizar algumas horas de debug!
